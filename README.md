# AACHIP-93-EEPROM-PROGRAM 使用 FT232H,FT2232H,FT4232H.
AACHIP 93 EEPROM PROGRAM 是針對 93 系列 Microwire 串列 EEPROM 的操作工具，用於資料備份、參數寫入與設備維護。

實際支援的晶片、燒錄介面、檔案格式，以及讀取、寫入、抹除與驗證功能，請參考各版本發布說明。

## 晶片與介面

93 系列常見型號包含 93C46、93C56、93C66 等；這些型號僅供系列辨識，並不代表本軟體全部支援。

| 訊號 | 用途 |
| --- | --- |
| CS | 晶片選擇 |
| SK／CLK | 通訊時脈 |
| DI | 傳入 EEPROM 的資料 |
| DO | EEPROM 回傳的資料 |
| VCC／GND | 電源與接地 |

部分晶片支援 x8／x16 資料組織，部分型號則為固定組織。請依完整料號與原廠資料手冊確認設定及接腳。

## 應用情境

- 備份與還原 EEPROM 設定資料。
- 寫入產品參數或初始化資料。
- 驗證 EEPROM 電路與通訊流程。
- 協助設備維修及資料比對。

## 下載與安裝

1. 前往本儲存庫的 **Releases** 頁面。
2. 下載適用版本；若為 ZIP，請先完整解壓縮。
3. 依版本說明安裝軟體及必要驅動。

## 基本操作流程

1. 確認 EEPROM 完整型號、工作電壓及 x8／x16 資料組織。
2. 依燒錄硬體說明接線，確認供電與接地。
3. 開啟軟體，選擇對應裝置及晶片設定。
4. 若版本提供讀取功能，先讀取並備份原始資料。
5. 載入資料檔案，核對容量及內容後執行寫入。
6. 若版本提供驗證功能，寫入完成後進行驗證。

## 注意事項

- 請使用符合晶片規格的電壓，勿直接連接不相容的訊號。
- x8／x16 組織、位址長度及 x16 資料的位元組順序必須設定正確。
- 寫入或抹除前請備份重要資料，操作期間保持供電穩定。
- 在板燒錄時，請確認其他元件不會同時驅動訊號，並避免反向供電。
- Microwire 與一般 SPI EEPROM 的指令及時序不同，不可直接套用其他系列的設定。
